A two-group test is only meaningful after you decide what counts as an independent sample. This guide uses one numeric feature measured in independent control and treated biological samples. It walks through the input contract, a Welch comparison, its uncertainty, and the separate problem of testing many features.

Format: Conceptual guide. For readers planning a two-group analysis, this guide works through a synthetic single-feature example and a multiple-testing review; prepare your own measurements only after confirming the independent experimental units.

Start with the experimental unit

Write down the unit that was independently assigned to a condition or independently sampled from the biological population. If treatment was applied to animals, the animal may be the unit; if it was applied to cultures, the independently prepared culture may be. Multiple reads, wells, fields of view, or repeated instrument measurements from one unit do not become independent biological replicates merely because they occupy separate rows. Summarize technical repeats at the biological-unit level or use a model that represents their nesting.

For a single feature, the comparison below targets the difference in group means, defined as treated minus control. It assumes independent observations within and between groups. If the same biological units are measured in both conditions, use a paired analysis with correctly matched units; the independent-samples code here is inappropriate. If samples share a litter, donor, batch, or other dependence, consider a design-aware model rather than treating each row as independent.

Before testing: confirm the sample mapping, condition labels, biological-unit IDs, and any pairing or blocking. A small p-value cannot repair pseudoreplication or confounding.

Input contract and reproducible setup

The runnable Python example expects two CSV files, each with a numeric column named value, one row per independent biological unit, and no duplicated technical measurements. Genuinely blank cells are discarded and counted; nonblank values that fail numeric conversion, infinities, a missing column, fewer than two retained values, or zero variance stop with an error. The output directory is created if needed. The included values are synthetic teaching fixtures, not biological evidence; replace them only with measurements whose experimental-unit structure you have checked.

# Run from a disposable working directory. Do not overwrite real data.
mkdir -p data results
printf "value\n8.9\n9.8\n10.4\n9.5\n" > data/control.csv
printf "value\n11.2\n10.7\n12.1\n11.4\n" > data/treated.csv

Install the packages in an environment you manage, then save this as compare_groups.py. SciPy 1.11 or newer is required for the confidence-interval method used here. The later FDR example also requires statsmodels. The script tests one feature. Its Welch confidence interval is for the treated-minus-control mean difference; Cohen's d is a standardized descriptive effect estimate, not a substitute for the difference in the feature's original units.

python -m pip install numpy pandas 'scipy>=1.11' statsmodels
python compare_groups.py data/control.csv data/treated.csv results

#!/usr/bin/env python3
import sys
from pathlib import Path
import numpy as np
import pandas as pd
from scipy import stats

if len(sys.argv) != 4:
    raise SystemExit("Usage: python compare_groups.py CONTROL.csv TREATED.csv OUTDIR")
control_path, treated_path, outdir = map(Path, sys.argv[1:])

def read_values(path):
    frame = pd.read_csv(path, dtype=str, keep_default_na=False, skip_blank_lines=False)
    if "value" not in frame.columns:
        raise ValueError(f"{path}: required column 'value' is missing")
    raw = frame["value"]
    blank = raw.isna() | raw.astype("string").str.strip().eq("")
    try:
        converted = pd.to_numeric(raw[~blank], errors="raise")
    except (ValueError, TypeError) as exc:
        raise ValueError(f"{path}: nonblank value is not numeric") from exc
    values = converted.to_numpy(dtype=float)
    print(f"{path}: discarded {int(blank.sum())} blank value(s)")
    if not np.isfinite(values).all():
        raise ValueError(f"{path}: values must be finite")
    if len(values) < 2:
        raise ValueError(f"{path}: need at least two non-missing units")
    if np.var(values, ddof=1) == 0:
        raise ValueError(f"{path}: sample variance is zero; inspect these data")
    return values

ctrl = read_values(control_path)
trt = read_values(treated_path)
outdir.mkdir(parents=True, exist_ok=True)

# Welch's test allows the two population variances to differ.
res = stats.ttest_ind(trt, ctrl, equal_var=False)
ci = res.confidence_interval(confidence_level=0.95)
mean_diff = float(np.mean(trt) - np.mean(ctrl))
pooled_sd = np.sqrt(((len(ctrl)-1)*np.var(ctrl, ddof=1) +
                     (len(trt)-1)*np.var(trt, ddof=1)) /
                    (len(ctrl)+len(trt)-2))
cohens_d = mean_diff / pooled_sd

pd.DataFrame([{
    "n_control": len(ctrl), "n_treated": len(trt),
    "mean_control": np.mean(ctrl), "mean_treated": np.mean(trt),
    "sd_control": np.std(ctrl, ddof=1), "sd_treated": np.std(trt, ddof=1),
    "mean_difference_treated_minus_control": mean_diff,
    "welch_t": res.statistic, "welch_df": res.df, "p_value": res.pvalue,
    "ci95_low": ci.low, "ci95_high": ci.high, "cohens_d_pooled_sd": cohens_d
}]).to_csv(outdir / "comparison.csv", index=False)
print(f"Wrote {outdir / 'comparison.csv'}")

Equivalent test in base R

R's built-in t.test uses Welch's two-sample method by default. This parallel example expects the same two CSV files and writes the estimate, interval, statistic, degrees of freedom, and p-value. It uses base R only.

#!/usr/bin/env Rscript
args <- commandArgs(trailingOnly = TRUE)
if (length(args) != 3) stop("Usage: Rscript compare_groups.R CONTROL.csv TREATED.csv OUTDIR")
read_values <- function(path) {
  d <- read.csv(path, check.names = FALSE, colClasses = "character",
                na.strings = character(), blank.lines.skip = FALSE)
  if (!("value" %in% names(d))) stop(paste(path, "must contain a value column"))
  raw <- trimws(as.character(d$value))
  blank <- is.na(d$value) | raw == ""
  x <- suppressWarnings(as.numeric(raw[!blank]))
  if (anyNA(x)) stop(paste(path, "contains a nonblank value that is not numeric"))
  cat(path, ": discarded ", sum(blank), " blank value(s)\n", sep = "")
  if (length(x) < 2 || any(!is.finite(x))) stop(paste(path, "needs at least two finite numeric values"))
  if (var(x) == 0) stop(paste(path, "sample variance is zero; inspect these data"))
  x
}
ctrl <- read_values(args[1])
trt <- read_values(args[2])
dir.create(args[3], recursive = TRUE, showWarnings = FALSE)
res <- t.test(trt, ctrl, var.equal = FALSE, conf.level = 0.95)
write.csv(data.frame(
  n_control = length(ctrl), n_treated = length(trt),
  mean_difference_treated_minus_control = mean(trt) - mean(ctrl),
  ci95_low = res$conf.int[1], ci95_high = res$conf.int[2],
  statistic = unname(res$statistic), df = unname(res$parameter), p_value = res$p.value
), file.path(args[3], "comparison_R.csv"), row.names = FALSE)

Output: comparison.csv contains the retained sample counts, group means and standard deviations, treated-minus-control estimate, Welch statistic/degrees of freedom/p-value, a 95% confidence interval for the mean difference, and pooled-SD Cohen's d. The confidence interval and estimate retain the feature's measurement units. A run on the synthetic fixture is a software check only; it does not establish a biological effect.

Inspect the data and interpret the comparison

  • Plot the raw observations by biological unit, alongside group summaries. With few samples, histograms and formal normality tests have little power to establish that a distribution is normal. Look for data-entry problems, severe skew, and influential observations, then check them against records instead of deleting them because they change a p-value.
  • Welch's two-sample t-test targets equality of population means for independent groups and does not assume equal population variances. It still relies on a suitable sampling/design structure and a mean-based model; very small samples, strong skew, or influential outliers can make inference fragile. No single diagnostic certifies assumptions.
  • The p-value describes how extreme a statistic at least this large would be under the null model and test assumptions. It is not the probability that the null is true, the probability the result is “due to chance,” or a measure of biological importance.
  • Read the mean difference and interval before the p-value. The interval shows values compatible with the data and model at its stated confidence level; it is not a probability distribution for the fixed true effect. Decide in advance what difference would matter biologically, using domain knowledge rather than generic small/medium/large labels.
  • A non-significant result does not establish no effect. It may reflect imprecision, limited independent replication, a small effect, or model mismatch. Increasing technical measurements alone does not replace additional independent biological units.

When thousands of features are tested

The example above produces one raw p-value. If a separate, appropriately specified analysis generates one valid p-value per feature, adjust the prespecified family together rather than interpreting thousands of unadjusted values as independent discoveries. The Benjamini–Hochberg procedure controls the expected false-discovery proportion under its conditions; dependence structure and analysis design matter, and the adjustment does not fix invalid p-values, confounding, or inappropriate feature filtering.

For a vector of p-values in Python, this compact example writes adjusted values in the same order as the input. The four values below are synthetic software-demo data only. For real analyses, obtain p-values from a design-appropriate model for every feature, document the tested family and filtering rules, then adjust that vector.

from pathlib import Path
import numpy as np
from statsmodels.stats.multitest import multipletests

# Create a tiny, synthetic input file in the current working directory.
Path("pvalues_all_features.txt").write_text("0.01\n0.04\n0.20\n0.80\n")
pvals = np.loadtxt("pvalues_all_features.txt")
if pvals.ndim != 1 or pvals.size == 0:
    raise ValueError("Expected a non-empty one-dimensional p-value vector")
if not np.isfinite(pvals).all() or ((pvals < 0) | (pvals > 1)).any():
    raise ValueError("P-values must be finite and between 0 and 1")
reject, p_adjusted, _, _ = multipletests(pvals, alpha=0.05, method="fdr_bh")
np.savetxt("pvalues_adjusted.txt", p_adjusted)
np.savetxt("discoveries_fdr05.txt", reject.astype(int), fmt="%d")
print("adjusted:", p_adjusted)
print("reject:", reject.astype(int))

Run the block from a disposable directory with statsmodels installed. For this four-value fixture, BH-adjusted values are [0.04, 0.08, 0.2666667, 0.8] (approximately), and the rejection flags at alpha 0.05 are [1, 0, 0, 0]. Adjusted values quantify multiplicity-adjusted evidence; a rejection is not proof of a biological effect. The input is one numeric p-value per line. The adjusted-value file preserves input order; the second file contains 1 for a rejected null and 0 otherwise at the specified alpha. Keep feature IDs in a parallel file and verify row alignment before joining results. Report the correction procedure, alpha, number and definition of tests, raw and adjusted p-values, effect estimates, and uncertainty where available.

Choose a method that matches the design

  • Paired measurements: analyze within-unit differences with a paired method, or fit a model that represents the repeated structure. Do not pair groups by row order.
  • Count-based sequencing measurements: use methods designed for count distributions and their mean–variance structure, with the experimental design represented. A t-test on raw counts is not the default differential-expression workflow.
  • Strong skew or influential values: inspect the measurement process and estimand. A transformation changes the scale and often the question; rank-based tests do not automatically test equality of means. Choose an alternative based on the scientific target and design.
  • Batch, donor, litter, or covariates: include them in a model only when the design supports estimating their effects. If condition is completely confounded with batch, statistical adjustment cannot separate the two.
  • Power and planning: define the smallest meaningful effect, outcome, design, and expected variability before choosing sample size. A post-hoc “observed power” calculation does not resolve an imprecise result; use a prospective design-specific calculation and document its assumptions.

Record an analysis plan

Before looking at group p-values, write a short plan naming the outcome/feature, comparison and direction, experimental unit, inclusion rules, independent or paired structure, covariates or blocks, primary model, diagnostic checks, multiplicity family and correction, and the effect size that would matter biologically. In the results, report the exact independent sample counts, missing-data handling, estimate with interval, test and settings, raw/adjusted p-values as appropriate, software versions, and limitations. Preserve reference-genome and annotation release details when feature mapping depends on them.

Use the checklist to decide whether this simple comparison fits. If you cannot identify independent units, if samples are paired or clustered, or if the feature is a sequencing count, stop before running it and choose a design-appropriate method.
