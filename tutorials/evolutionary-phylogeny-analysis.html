Evolutionary Phylogeny

NM

Nasir Mahmood Abbasi, PhD

Bioinformatics Educator

Tested on: Python 3.11, R 4.3.2, Ubuntu 24.04

Learning objectives and prerequisites

By the end of this lesson you will be able to:

  • Produce a reproducible multiple sequence alignment (MSA) for homologous sequences using Kalign.
  • Build a phylogenetic tree from that alignment using MEGA-CC (command-line MEGA) or alternative CLI tools (IQ-TREE, FastTree).
  • Record and interpret key analysis choices: alignment file, evolutionary model or method, rooting strategy, and support values.
  • Critically evaluate what the resulting tree does and does not demonstrate about evolutionary relationships.

Prerequisites:

  • Familiarity with biological sequence files (FASTA), basic UNIX command line, and the concept of homologous characters and multiple sequence alignment.
  • Access to a Unix-like environment (Linux, macOS, or WSL) with Conda/Mamba or direct binaries for the tools mentioned. The tutorial uses file paths as examples—adapt them to your workspace.

Why evolutionary phylogeny matters (biological and computational context)

Phylogenetic analysis reconstructs relationships among genes, proteins, or organisms by comparing homologous characters (nucleotides or amino acids). Trees summarize hypotheses of shared ancestry: topology (branching pattern) suggests relative relationships, branch lengths often represent estimated genetic change, and support values indicate statistical confidence in clades under the chosen model and data. Phylogenies are used in systematics, comparative genomics, functional inference, and epidemiology, but they are hypotheses, not definitive histories; results depend on the input alignment, model choice, taxon sampling, and methodological assumptions.

Computationally, robust phylogenetic inference requires two main preprocessing steps: (1) generate a reliable MSA that attempts to align homologous positions across sequences, and (2) select a phylogenetic method (distance, maximum likelihood, Bayesian, or approximate methods) with a clear statement of the evolutionary model and support strategy (bootstraps, posterior probabilities). This tutorial emphasizes reproducible command-line workflows and explicit recording of settings.

Reproducible workflow (sequential)

Overview: work in a project directory containing raw sequences, intermediate files, configuration files, and results. The commands below are realistic examples and should be run after creating an appropriate environment. Replace filenames and paths with your local names.

1) Prepare a project folder and raw input

# Create a project directory (safe operation)
mkdir -p ~/phylogeny-project/results
cd ~/phylogeny-project

# Place your unaligned FASTA file here (example path)
# expected input: sequences.fasta — a plain FASTA file with sequence identifiers and sequences
ls -l sequences.fasta

Files you should have at this stage:

  • sequences.fasta — raw unaligned nucleotide or protein sequences in FASTA format.
  • A writable results/ directory for outputs.

2) Install tools (recommended: use Conda/Mamba)

# Create and activate a reproducible environment (example)
mamba create -n phylogeny_env -y kalign iqtree megacc fasttree
mamba activate phylogeny_env

# If using conda instead of mamba, replace 'mamba' with 'conda' and adjust '-y' flags.

Notes: package names and channels may change over time. If you prefer individual installation or binary downloads, consult the official project pages in the References section.

3) Multiple sequence alignment with Kalign

Kalign is a fast aligner suitable for moderate to large datasets. For protein sequences, align amino acids; for nucleotide analyses of coding sequences, align by translated amino acids when appropriate, or use codon-aware methods (not covered here). 

# Align sequences (FASTA input -> FASTA output)
kalign -i sequences.fasta -o results/aligned_sequences.fasta

# To output in Clustal format (optional)
kalign -i sequences.fasta -f clu -o results/aligned_sequences.aln

What these commands produce:

  • results/aligned_sequences.fasta — aligned sequences in FASTA format (gaps inserted).
  • Optionally results/aligned_sequences.aln — Clustal format alignment.

4) Inspect the alignment

# Quick text-based inspection; view header and first alignment block
head -n 200 results/aligned_sequences.fasta

# Summary statistics using seqmagick or simple python (optional)
# Install seqmagick if desired: mamba install -c bioconda seqmagick
seqmagick info results/aligned_sequences.fasta

Things to check:

  • Do sequence names match expectations and are unique?
  • Are there long stretches of gaps or sequences with excessive missing data?
  • Has the alignment preserved expected conserved motifs (if known)?

5) Build a tree with MEGA-CC (command-line MEGA)

MEGA-CC requires a configuration (.mao) file that records method parameters. Best practice: create the .mao using the MEGA GUI to ensure correct structure, then edit or version-control it. Here we show how to run MEGA-CC when you already have a settings file. 

# Example file locations:
# results/aligned_sequences.fasta  (input alignment)
# ML_Tree_Settings.mao             (MEGA options file you prepared)

# Run MEGA-CC (adjust path to megacc binary if not on PATH)
megacc -a ML_Tree_Settings.mao -d results/aligned_sequences.fasta -o results/megacc_output

Expected MEGA outputs (look in results/megacc_output/):

  • *.nwk — Newick-format tree files (may be rooted/unrooted depending on settings).
  • Log files and result summaries that include substitution model, likelihood, and support values (if bootstraps were requested).

Important: record the exact ML_Tree_Settings.mao used, the MEGA-CC version string (run megacc --version), and the full command line in a command.txt file in your project folder for reproducibility.

6) Alternative: build with IQ-TREE (explicit model selection & bootstraps)

IQ-TREE exposes model selection and bootstrap settings in the command line and is commonly used for ML trees with automatic model testing (ModelFinder). 

# Run IQ-TREE with automatic model selection (-m MFP), 1,000 ultrafast bootstraps (-B 1000),
# and save outputs to results/iqtree_run (IQ-TREE will create files with the prefix)
iqtree -s results/aligned_sequences.fasta -m MFP -B 1000 -pre results/iqtree_run

# To show the version for provenance
iqtree --version

IQ-TREE will produce:

  • results/iqtree_run.treefile — ML tree with branch lengths.
  • results/iqtree_run.ufboot — bootstrap trees (if bootstraps were requested).
  • results/iqtree_run.log and results/iqtree_run.iqtree — model selection output, log-likelihoods, and parameter estimates.

7) FastTree for very large datasets (approximate ML)

# FastTree for nucleotide sequences (default is approximately ML); use -nt for nucleotides
FastTree -nt results/aligned_sequences.fasta > results/fasttree.nwk

FastTree is optimized for speed and will produce one Newick tree file. It makes approximations that are appropriate for exploratory analyses of very large alignments but may not match more rigorous ML methods on smaller datasets.

Output inspection and interpretation

After producing trees, inspect both the tree file contents and the associated logs to interpret meaningfully:

  • Open the Newick file in a tree viewer (FigTree, iTOL, Dendroscope) or use text tools to display structure. Example: cat results/iqtree_run.treefile.
  • Check support values: bootstrap percentages (IQ-TREE) or ultrafast bootstrap (UFboot) values near nodes. High support (commonly >70–95% depending on method) suggests the data are consistent with that clade under the chosen model and sample of sites, but support thresholds are heuristic.
  • Examine branch lengths: long branches indicate more inferred substitutions; very short branches can indicate unresolved relationships.
  • Model choice: in IQ-TREE logs, ModelFinder reports the best-fitting substitution model and AIC/BIC scores. Record this model as part of your analysis provenance.
  • Rooting: many ML methods produce unrooted trees. Root placement affects interpretation of directionality (ancestor-descendant). Rooting requires an explicit outgroup (a lineage known to be outside the ingroup) or methods like midpoint rooting; record which approach you used.

What a plausible result means:

  • Consistent clades with strong support indicate that, under the alignment and model used, those taxa share a closer relationship to each other than to others in the set.
  • Branch-length patterns can suggest relative rates of evolution but do not alone prove absolute timing or direction of change without calibration.

What the tree does NOT prove:

  • A single tree does not definitively establish true historical events—trees are model-dependent hypotheses.
  • Low support nodes indicate unresolved relationships, not necessarily absence of relationship.
  • Convergence, horizontal gene transfer, recombination, or alignment error can mislead inference; additional evidence is often required to support strong evolutionary claims.

Troubleshooting (symptoms, likely causes, fixes)

  • Symptom: Alignment shows sequences with many terminal gaps or extremely short aligned length.
    Likely cause: Mixed sequence types (proteins and nucleotides) or truncated sequences.
    Fix: Verify sequence type and convert consistently (translate nucleotides to protein if aligning coding sequences by amino acids), remove obviously incomplete sequences, and re-run Kalign.
  • Symptom: MEGA-CC fails with a parsing error for the .mao file.
    Likely cause: The .mao file is corrupted or produced by an incompatible MEGA version.
    Fix: Recreate the .mao file using the same MEGA GUI version as your MEGA-CC installation, or use IQ-TREE which is fully command-line driven and self-documenting.
  • Symptom: Very low bootstrap support across many nodes.
    Likely cause: Insufficient informative sites, poor alignment, or wrong model class.
    Fix: Inspect alignment for ambiguous regions, consider trimming poorly aligned columns (with caution), increase taxon sampling, or perform model testing (IQ-TREE's ModelFinder). Consider alternative loci or concatenated datasets if appropriate.
  • Symptom: Unexpected topologies contrasting well-established relationships.
    Likely cause: Long-branch attraction, recombination, paralogy (mixing paralogous gene copies), or poor alignment.
    Fix: Check for paralogs (sequence similarity clusters), remove recombining regions, use site-heterogeneous models or partitioned analyses, and validate input sequences.
  • Symptom: Tool installation issues or missing binaries.
    Likely cause: Channel mismatch or version conflicts in Conda/Mamba environment.
    Fix: Create a fresh environment, install packages from bioconda channel with the required conda-forge priority and channels ordered: conda config --add channels conda-forge; conda config --add channels bioconda. Consult official install docs in References.

Limitations, version and reference-data caveats, and responsible use

Limitations:

  • Results depend on sequence sampling, alignment quality, model choice, and method. No single method guarantees the "true" tree.
  • Bootstraps and posterior probabilities measure data consistency under chosen assumptions, not absolute truth.
  • Fast approximate methods (FastTree) trade accuracy for speed and may be inappropriate when detailed model-based inference is needed.

Version and reference-data caveats:

  • Software behavior and available models change across versions. Always record program versions (for example, run iqtree --version, megacc --version, kalign --version) and software source.
  • Substitution model sets differ between programs; the same model name may have different parameterizations. Report the exact model string and where it was selected.
  • Reference data (taxon names, outgroup selection) can bias results—document why each sequence was included and any sequences omitted.

Responsible use:

  • Avoid overinterpreting trees. When making biological claims (e.g., taxonomic changes, epidemiological inferences), combine phylogenetic evidence with additional data and appropriate statistical tests.
  • Follow data-sharing policies and privacy considerations for sequence data (e.g., human-derived viruses) and cite sequence sources.

Concise next-step checklist

  1. Record provenance: save copies of aligned_sequences.fasta, the MEGA .mao file (if used), IQ-TREE logs, and the exact commands in command.txt.
  2. Visualize the primary tree in a GUI (FigTree or iTOL) and annotate clades of interest.
  3. If nodes of interest have low support, consider additional loci, remove problematic sequences, or try alternative models/partitioning.
  4. Prepare a figure caption that lists alignment method, program versions, substitution model, bootstrap method and replicates, and rooting choice.
  5. Deposit alignment and tree files in an archive (e.g., Dryad, Zenodo) if publishing results to enable reproducibility.
