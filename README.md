## 📋 Overview
A comprehensive educational and documentation website designed to bridge the gap between High-Performance Computing (HPC) Bash environments and R-based data analysis workflows. 

## 🗂️ Repository Contents
This repository hosts the source code for the S2R web portal, featuring:
- **HPC Tutorials:** Visual guides (via MobaXterm/SSH) on navigating cluster environments and managing Conda environments.
- **Bioinformatics Workflows:** Step-by-step guides transitioning raw sequencing data (processed in Shell) into statistical analysis frameworks (processed in R).
- **Deployment & Actions:** Automated GitHub Actions (`static.yml`) for continuous deployment to GitHub Pages.
