scRNA-seq Basics

NM

Nasir Mahmood Abbasi, PhD

Bioinformatics Educator

Tested on: R 4.3.2, Seurat v5.0.1, Ubuntu 24.04

Learning objectives and prerequisites

Learning objectives. After completing this tutorial you will be able to:

  • Perform rigorous quality control (QC) on a 10x Genomics single-cell RNA-seq (scRNA-seq) count matrix.
  • Normalize and identify highly variable genes (HVGs).
  • Compute PCA and choose components for downstream analysis using an elbow plot and heuristic checks.
  • Generate 2D embeddings (UMAP) and perform graph-based clustering (Leiden or Louvain).
  • Interpret QC metrics and common failure modes, and make principled adjustments to thresholds based on biology.

Prerequisites. Working knowledge of the Linux command line, basic R or Python programming, familiarity with count matrices and gene identifiers, and introductory statistics (variance, correlation, dimensionality reduction). You should have either R (>=4.0) with Seurat installed or Python (>=3.8) with Scanpy. Example command-line utilities used: wget or curl for downloads, and unzip/tar for archive extraction.

Why this matters: biological and computational context

Single-cell RNA sequencing profiles gene expression at the level of individual cells. This enables discovery of cell types, states, and transitions that would be hidden in bulk measurements. However, the raw data are noisy: many droplets are empty or contain ambient RNA, some cells are dying and produce biased libraries, and multiplets (doublets) can create hybrid expression profiles. Robust QC and careful downstream processing (normalization, feature selection, dimensionality reduction, clustering) are essential to ensure biological interpretations reflect true biology rather than technical artefacts.

Two widely used toolkits for scRNA-seq are Seurat (R) and Scanpy (Python). This tutorial provides parallel example commands for both so you can reproduce the pipeline in your preferred environment. The workflow is demonstrated on the 10x Genomics PBMC 3k dataset as a pedagogical example, but the same principles apply to other datasets; thresholds should be adapted to your tissue and experimental protocol.

Required files and workspace

Before you start, prepare a working directory and ensure you have the 10x matrix files (or your own count matrix in 10x or Matrix Market / TSV format). For the PBMC 3k example, create a directory named data/pbmc3k/ and place the 10x filtered matrix files there (barcodes.tsv, genes.tsv or features.tsv, and matrix.mtx). The commands below assume these paths:

  • data/pbmc3k/filtered_feature_bc_matrix/ — containing the 10x files (preferred 10x v3+ layout may use features.tsv.gz).
  • For R: you will create an R object file results/pbmc_seurat.rds.
  • For Python: you will create AnnData files results/pbmc_scanpy.h5ad and intermediate figures in results/figures/.

Reproducible sequential workflow

Seurat (R) workflow

# R script: scripts/01_seurat_qc_clustering.R
# Input: data/pbmc3k/filtered_feature_bc_matrix/
# Output: results/pbmc_seurat.rds and figures saved to results/figures/

library(Seurat)          # v4/5
library(patchwork)       # for arranging plots (optional)

dir.create("results/figures", recursive = TRUE, showWarnings = FALSE)

# 1) Load 10x data
pbmc.data <- Read10X(data.dir = "data/pbmc3k/filtered_feature_bc_matrix/")
pbmc <- CreateSeuratObject(counts = pbmc.data, project = "pbmc3k", min.cells = 3, min.features = 200)

# 2) Compute percent mitochondrial reads (human: genes starting with MT-)
pbmc[["percent.mt"]] <- PercentageFeatureSet(pbmc, pattern = "^MT-")

# 3) Visualize QC metrics and choose thresholds
png("results/figures/qc_violin.png", width=1200, height=400)
VlnPlot(pbmc, features = c("nFeature_RNA", "nCount_RNA", "percent.mt"), ncol = 3)
dev.off()

# 4) Example filtering (adjust thresholds to your experiment)
pbmc <- subset(pbmc, subset = nFeature_RNA > 200 & nFeature_RNA < 2500 & percent.mt < 5)

# 5) Normalize, find variable features, scale
pbmc <- NormalizeData(pbmc, normalization.method = "LogNormalize", scale.factor = 10000)
pbmc <- FindVariableFeatures(pbmc, selection.method = "vst", nfeatures = 2000)
all.genes <- rownames(pbmc)
pbmc <- ScaleData(pbmc, features = all.genes)

# 6) PCA
pbmc <- RunPCA(pbmc, features = VariableFeatures(pbmc))
png("results/figures/pca_elbow.png", width=800, height=600)
ElbowPlot(pbmc, ndims = 50)
dev.off()

# 7) Neighbors, clustering, UMAP (use dims chosen from ElbowPlot)
pcs <- 1:10
pbmc <- FindNeighbors(pbmc, dims = pcs)
pbmc <- FindClusters(pbmc, resolution = 0.5)   # Louvain by default; use algorithm = 4 for Leiden in Seurat v4+
pbmc <- RunUMAP(pbmc, dims = pcs)
png("results/figures/umap_clusters.png", width=800, height=600)
DimPlot(pbmc, reduction = "umap", label = TRUE)
dev.off()

# 8) Save object
saveRDS(pbmc, file = "results/pbmc_seurat.rds")

What each command produces:

  • VlnPlot figure for per-cell QC distributions (nFeature_RNA = number of genes detected per cell, nCount_RNA = UMI counts, percent.mt = fraction of mitochondrial reads).
  • Subsetted Seurat object with filtered cells (the subset call produces a smaller in-memory object).
  • ElbowPlot saved as PNG for choosing the number of PCs.
  • UMAP plot and saved Seurat object results/pbmc_seurat.rds.

Scanpy (Python) workflow

# Python script: scripts/01_scanpy_qc_clustering.py
# Input: data/pbmc3k/filtered_feature_bc_matrix/
# Output: results/pbmc_scanpy.h5ad and figures in results/figures/

import scanpy as sc
import os

os.makedirs("results/figures", exist_ok=True)

# 1) Read 10x filtered matrix (Scanpy will detect format)
adata = sc.read_10x_mtx("data/pbmc3k/filtered_feature_bc_matrix/", var_names='gene_symbols', cache=True)
adata.var_names_make_unique()

# 2) Basic QC metrics
adata.obs['n_counts'] = adata.X.sum(axis=1).A1 if hasattr(adata.X, "A1") else adata.X.sum(axis=1)
adata.obs['n_genes'] = (adata.X > 0).sum(axis=1).A1 if hasattr(adata.X, "A1") else (adata.X > 0).sum(axis=1)
# percent mitochondrial (human: MT-)
mt_mask = adata.var_names.str.upper().str.startswith('MT-')
adata.obs['percent_mt'] = (adata[:, mt_mask].X.sum(axis=1).A1 / adata.obs['n_counts']) * 100

# 3) QC plotting for inspection
sc.pl.violin(adata, ['n_counts', 'n_genes', 'percent_mt'], jitter=0.4, multi_panel=True, save='_qc_violin.png')

# 4) Filter cells (adjust thresholds for your data)
sc.pp.filter_cells(adata, min_genes=200)
adata = adata[adata.obs['n_genes'] < 2500, :]
adata = adata[adata.obs['percent_mt'] < 5, :]

# 5) Normalize, log-transform, HVG, scale
sc.pp.normalize_total(adata, target_sum=1e4)
sc.pp.log1p(adata)
sc.pp.highly_variable_genes(adata, n_top_genes=2000, flavor='seurat_v3')
adata.raw = adata  # store raw for later
adata = adata[:, adata.var.highly_variable]

sc.pp.scale(adata, max_value=10)

# 6) PCA and elbow inspection
sc.tl.pca(adata, svd_solver='arpack')
sc.pl.pca_variance_ratio(adata, log=True, save='_pca_elbow.png')

# 7) Neighbors, Leiden, UMAP
sc.pp.neighbors(adata, n_neighbors=10, n_pcs=10)
sc.tl.leiden(adata, resolution=0.5)
sc.tl.umap(adata)
sc.pl.umap(adata, color=['leiden'], save='_umap_clusters.png')

# 8) Save AnnData object
adata.write("results/pbmc_scanpy.h5ad")

What each command produces:

  • QC violin plots saved under results/figures/ for visual threshold selection.
  • Filtered AnnData object results/pbmc_scanpy.h5ad that contains expression, computed metrics, and cluster labels.
  • PCA variance ratio figure to help pick the number of components.
  • UMAP and cluster plots saved as image files.

Output inspection and interpretation

At each stage inspect both numeric summaries and visual diagnostics. Key places to look and how to interpret them:

  • QC violin/density plots: These show distributions of genes/cell (nFeature_RNA/n_genes), UMI counts, and percent mitochondrial reads. A small left-side peak near zero for n_genes suggests many empty droplets or low-quality cells. An excessive right tail for n_genes or n_counts can indicate multiplets (doublets).
  • Percent mitochondrial (percent.mt): Elevated mitochondrial fraction often indicates cell stress or membrane rupture. Typical cutoffs are dataset-dependent; common tutorial values are 5–20%. A high global level (e.g., median > 15%) suggests problems with dissociation or sample handling.
  • Retention rate after QC: Calculate fraction of cells retained. Very low retention (< 50–70%) often indicates tissue-specific issues or that thresholds are too strict. Conversely, keeping nearly 100% without inspection risks retaining low-quality cells.
  • Elbow plot / PCA variance: The "elbow" shows when additional PCs explain diminishing variance. Use the elbow as a guide (e.g., 10–30 PCs) but also inspect biological interpretability: do clusters separate only when you include more PCs? Visualize marker genes across PCs when uncertain.
  • UMAP/clustering: UMAP is a visualization and not a clustering algorithm. If cluster separations are weak in UMAP, check whether the clustering is driven by technical covariates (sequencing depth, percent.mt) by coloring UMAP by those metrics.

What a plausible result means, and what it does NOT prove:

  • Finding discrete clusters that correspond to known immune cell types (e.g., T cells, B cells, monocytes) is consistent with expected biology in PBMC samples. This supports—but does not prove—the claim that clusters are distinct cell types; validation with marker genes and orthogonal assays (flow cytometry, CITE-seq surface markers) strengthens conclusions.
  • Detecting a small cluster with high n_genes and n_counts might indicate doublets but could also be a biologically large or activated cell type. Do not automatically remove such clusters without checking marker expression.
  • Good-looking UMAPs are necessary but not sufficient evidence of biological validity: batch effects, normalization artifacts, or inappropriate gene selection can create misleading visual separation.

Troubleshooting

Common symptoms, likely causes, and practical fixes:

  • Symptom: Very low median genes/cell and many cells with zero or few genes.
    Likely causes: Using the raw (unfiltered) matrix that includes ambient RNA, degraded sample, or wrong file path leading to an empty object.
    Fixes: Confirm the input files (matrix.mtx, barcodes.tsv) are present and non-empty. Use the 10x filtered matrix if intended. Check sample QC at the wet-lab stage.
  • Symptom: High fraction of mitochondrial reads across most cells.
    Likely causes: Cell lysis during dissociation, poor viability, or sequencing of RNA from dying cells.
    Fixes: Re-examine experimental protocol; increase mito cutoff if cells are known to be mitochondrial-rich (e.g., muscle), but document the rationale. Consider removing cells with extreme percent.mt values and check downstream impact.
  • Symptom: Clusters correlate with n_counts or percent.mt rather than biological markers.
    Likely causes: Technical variation dominating the signal (batch effects, library size differences).
    Fixes: Regress out technical covariates during scaling (e.g., scale.data with vars.to.regress in Seurat) or apply batch-correction tools (Harmony, Seurat IntegrateData, Scanpy’s combat/regress) when appropriate.
  • Symptom: Too many small clusters or over-clustering.
    Likely causes: High clustering resolution or too many PCs with noise.
    Fixes: Lower clustering resolution (e.g., from 1.0 to 0.4), reduce number of PCs, or merge clusters based on marker gene expression.
  • Symptom: No clear elbow in PCA variance plot.
    Likely causes: Gradual decay of variance due to continuous biological gradients or high noise.
    Fixes: Use alternative criteria (JackStraw in Seurat, permutation tests, or look at PC loadings and marker genes) and combine with biological knowledge.

Limitations, version and reference-data caveats, and responsible-use notes

Limitations and caveats to remember:

  • Tool versions matter. Seurat and Scanpy APIs and defaults change between major releases; scripts should pin package versions or be run in a reproducible environment (container or conda environment). Record the exact package versions used when producing results.
  • Reference genomes and gene identifiers: 10x datasets can be aligned to different references (hg19, GRCh38). Gene name prefixes (e.g., MT- vs mt-) vary; pattern matching for mitochondrial genes must reflect your annotation source.
  • Thresholds (percent.mt, gene/UMI cutoffs, number of PCs, clustering resolution) are dataset- and biology-specific. Default tutorial values are starting points, not universal rules. For disease contexts (e.g., tumors), many canonical thresholds are inappropriate and can remove biologically relevant populations.
  • UMAP is non-deterministic by default; set random seeds for reproducible embeddings when necessary (Seurat and Scanpy allow RNG control).
  • Ethical/responsible use: scRNA-seq from human samples may contain personally identifiable information in metadata. Follow data-use agreements and IRB guidance for controlled-access datasets.

Next-step checklist (concise)

  1. Confirm input files: data/pbmc3k/filtered_feature_bc_matrix/ contains valid 10x files.
  2. Run the provided R or Python script and inspect saved figures in results/figures/.
  3. Adjust QC thresholds based on violin plots and biological expectations; re-run filtering if needed.
  4. Decide on number of PCs using ElbowPlot and biological tests (marker separation); recompute neighbors and clustering if you change PCs.
  5. Annotate clusters with marker genes, and validate with orthogonal data where available.
  6. Record software versions, random seeds, and input file checksums for reproducibility.
