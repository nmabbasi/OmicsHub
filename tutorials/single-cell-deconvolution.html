Bulk RNA-seq cell-type deconvolution with MuSiC

NM

Nasir Mahmood Abbasi, PhD

Bioinformatics Educator

Learning pathPrevious prerequisiteStatistics for BioinformaticsBrowseAll tutorialsSuggested nextReturn to single-cell choices

Bulk RNA-seq combines RNA from many cells, so a change in a gene's abundance can reflect a change in cell mixture, expression within cells, or both. This walkthrough uses MuSiC to estimate composition from an annotated single-cell reference, then shows what must be checked before interpreting those estimates.

Format: Conceptual guide. For analysts with prepared bulk counts and an annotated single-cell reference, this guide walks through input review, a MuSiC fit scaffold, and interpretation checks. No data are supplied; readers must prepare both objects and their metadata.

Scope and inputs

MuSiC is a reference-based method designed to use cross-subject single-cell data. You need bulk gene-expression measurements and a single-cell reference with gene counts, cell-type labels, and donor/sample IDs. The code below is an analysis scaffold: replace the named objects and metadata fields with your data, and verify package versions and preprocessing before running it.

What the estimate means and how MuSiC weights genes

A bulk profile is modeled as a non-negative linear combination of reference cell-type profiles. MuSiC (Wang et al., 2019) improves on ordinary unweighted non-negative least squares (NNLS) through three design choices that every analyst should check against their cohort:

  • Cross-subject variance weighting: instead of requiring a fixed pre-selected marker gene list, MuSiC estimates gene-specific cross-donor variance from a multi-subject single-cell reference. Genes with low cross-subject variance (stable lineage markers across donors) receive high weight, whereas genes that fluctuate sharply across donors (dissociation-induced immediate-early genes, interferon bursts, or ambient RNA contaminants) are downweighted automatically.
  • Cell-size scaling (cell_size): metabolically active macrophages, plasma cells, and malignant epithelial cells contain substantially more total mRNA per cell than resting naive lymphocytes. MuSiC accounts for library-size differences per cell type so that estimated proportions reflect cell fractions rather than raw mRNA mass; you can inspect or supply custom cell sizes via the cell_size argument in music_prop().
  • Tree-guided recursive deconvolution: when closely related subpopulations (for example naive CD4+, memory CD4+, regulatory T, and exhausted CD8+ T cells) share highly collinear expression profiles, flat single-step NNLS suffers variance inflation and unstable trade-offs between sibling clusters. MuSiC's tree-guided mode (music_prop.cluster()) groups collinear clusters into broad parent lineages first, estimates parent proportions using lineage-discriminating genes, and then resolves child subtypes within each lineage.

Estimated fractions remain strictly conditional on the cell types represented in the reference. If a major population is absent, or if reference and bulk samples differ substantially in tissue, disease state, or RNA extraction chemistry (for example poly(A) single-cell capture vs ribo-depleted FFPE bulk RNA-seq), NNLS redistributes the unmodeled signal across the closest available reference profiles while still normalizing the reported fractions to sum to 1.0. Estimating proportions also does not establish that a cell population caused a clinical phenotype; outcome associations require an independent sample-level statistical model.

Check the reference before fitting

  1. Confirm cell-type annotations and donor identifiers are present for every reference cell. MuSiC uses the cell-type field as clusters and donor/sample field as samples.
  2. Check that bulk and single-cell features use the same gene identifier system. Inspect duplicated and missing row names, then quantify shared features in both directions; investigate unexpectedly low overlap before fitting rather than relying on a universal cutoff.
  3. Review whether the reference covers the tissue, condition, and cell states in the bulk cohort. Record omitted or rare populations rather than treating the listed types as exhaustive truth.
  4. Use raw read counts for both bulk and single-cell expression, as specified in the MuSiC vignette; do not pass log-transformed values merely because they are convenient for visualization. Check the installed package guidance before adapting preprocessing.

Before running

The bulk matrix should have genes in rows and samples in columns; its row names must match the single-cell reference gene identifiers. The reference must be a SingleCellExperiment with counts and the metadata columns named in the call. Do not use the old ExpressionSet-based single-cell example: current MuSiC documentation specifies sc.sce.

Run MuSiC with your prepared objects

The code assumes that bulk_counts is a genes-by-bulk-samples matrix and sc_reference is a prepared SingleCellExperiment. Both objects are supplied by you; this page does not download or fabricate biological data. MuSiC's official vignette documents installation via devtools::install_github("xuranw/MuSiC") and describes raw read-count inputs. In a fresh R session, first check R.version.string, then install/load the package and required class; record packageVersion("MuSiC"), packageVersion("SingleCellExperiment"), and BiocManager::version() with the run rather than assuming an untested version combination. If installation or class loading fails, stop and resolve that environment issue before fitting. For prepared-object context, follow the vignette's data-preparation example; this page does not construct these objects from files.

library(MuSiC)
library(SingleCellExperiment)

# Replace these names with your prepared objects and metadata fields.
stopifnot(is.matrix(bulk_counts),
          !is.null(rownames(bulk_counts)),
          !is.null(colnames(bulk_counts)),
          inherits(sc_reference, "SingleCellExperiment"))
stopifnot(all(c("cell_type", "donor_id") %in% colnames(colData(sc_reference))))

# Keep shared genes in the same order in both inputs.
shared_genes <- intersect(rownames(bulk_counts), rownames(sc_reference))
if (length(shared_genes) == 0L) {
  stop("No shared gene identifiers; check naming and species.")
}
if (anyDuplicated(rownames(bulk_counts)) || anyDuplicated(rownames(sc_reference))) {
  stop("Duplicate feature identifiers found; resolve them before fitting.")
}
if (anyNA(rownames(bulk_counts)) || anyNA(rownames(sc_reference)) ||
    any(!nzchar(rownames(bulk_counts))) || any(!nzchar(rownames(sc_reference)))) {
  stop("Missing or empty feature identifiers found; resolve them before fitting.")
}
message("Shared genes: ", length(shared_genes), " / ", nrow(bulk_counts),
        " bulk features; ", length(shared_genes), " / ", nrow(sc_reference),
        " reference features.")
if (length(shared_genes) < 2L) stop("Too few shared genes to fit; investigate identifiers and inputs.")
bulk_use <- bulk_counts[shared_genes, , drop = FALSE]
sc_use <- sc_reference[shared_genes, ]

music_results <- music_prop(
  bulk.mtx = bulk_use,
  sc.sce = sc_use,
  clusters = "cell_type",
  samples = "donor_id"
)

# Weighted estimates: rows are bulk samples; columns are cell types.
prop_estimates <- music_results$Est.prop.weighted
stopifnot(is.data.frame(prop_estimates) || is.matrix(prop_estimates))
dim(prop_estimates)
head(prop_estimates)

The identifier columns cell_type and donor_id are examples, not required names; change them to columns actually present in colData(sc_reference). MuSiC uses genes shared between the bulk matrix and reference when markers are left at their default. The output list also contains an all-gene NNLS estimate, gene weights, fit summaries, and variance estimates in the documented implementation. Check the installed version's documentation if an output name differs.

Inspect, plot, and interpret

First inspect dimensions, sample names, cell-type columns, missing values, and whether estimates are finite. MuSiC documents estimates normalized across the included cell types. That sum is conditional on the cell types included in the fit; it does not prove that the reference contains every cell population in the tissue.

# Basic output checks; compare cross-subject weighted MuSiC vs unweighted all-gene NNLS.
stopifnot(nrow(prop_estimates) == ncol(bulk_use))
stopifnot(all(is.finite(as.matrix(prop_estimates))))
range(as.matrix(prop_estimates), na.rm = TRUE)
rowSums(as.matrix(prop_estimates))

nnls_estimates <- music_results$Est.prop.allgene
max_method_diff <- apply(abs(as.matrix(prop_estimates) - as.matrix(nnls_estimates)), 2, max)
print(round(max_method_diff, 3))

# Reshape and visualize estimated cell-type proportions across samples (template).
library(ggplot2)
plot_df <- as.data.frame(as.table(as.matrix(prop_estimates)))
names(plot_df) <- c("bulk_sample", "cell_type", "proportion")
ggplot(plot_df, aes(x = bulk_sample, y = proportion, fill = cell_type)) +
  geom_col(width = 0.8) +
  labs(
    title = "MuSiC estimated cell-type fractions (conditional on reference)",
    x = "Bulk RNA-seq sample",
    y = "Estimated proportion"
  ) +
  theme_bw() +
  theme(axis.text.x = element_text(angle = 45, hjust = 1))

Comparing music_results$Est.prop.weighted against music_results$Est.prop.allgene is an immediate diagnostic: large discrepancies on a specific cell type warn either that unweighted NNLS is being pulled by high-variance donor-specific genes or that two reference clusters are nearly collinear. Do not treat a stacked bar chart as biological validation; validate against flow cytometry, immunohistochemistry, or held-out pseudo-bulk mixtures with known ground-truth fractions.

Worked R validation check: pseudo-bulk mixtures, variance weighting, and omitted tumour populations

Before running MuSiC on patient bulk cohorts, construct artificial pseudo-bulk mixtures from held-out reference donors so you know the exact true fractions. The self-contained base-R script below (executed locally on R 4.6.1; no external packages required) demonstrates two essential deconvolution diagnostics on an invented 3-donor reference: first, how inverse cross-donor variance weighting stabilizes NNLS against a high-variance stress gene (STRESS_VAR); second, how deconvolving a 45%-tumour bulk mixture against an immune-only reference still returns immune proportions summing to 1.000:

set.seed(20261118)
genes <- c("CD3D", "TRBC1", "LYZ", "S100A8", "COL1A1", "STRESS_VAR")

donor_profiles <- list(
  donor_1 = cbind(T_cell = c(42, 38, 1, 0, 0, 15),
                  Monocyte = c(1, 0, 95, 88, 1, 20),
                  Fibroblast = c(0, 0, 2, 1, 160, 10)),
  donor_2 = cbind(T_cell = c(45, 36, 1, 1, 0, 240),
                  Monocyte = c(0, 1, 90, 92, 2, 15),
                  Fibroblast = c(1, 0, 1, 1, 150, 12)),
  donor_3 = cbind(T_cell = c(40, 41, 0, 1, 1, 30),
                  Monocyte = c(1, 0, 98, 85, 1, 210),
                  Fibroblast = c(0, 1, 1, 0, 170, 14))
)
for (d in names(donor_profiles)) rownames(donor_profiles[[d]]) <- genes

arr <- simplify2array(donor_profiles)
X_ref <- apply(arr, c(1, 2), mean)
gene_var <- apply(arr, 1, function(m) mean(apply(m, 1, var)))
w_inv_var <- 1 / (gene_var + 1)

X_heldout <- cbind(
  T_cell     = c(43, 39, 1, 0, 0, 25),
  Monocyte   = c(1, 0, 93, 89, 1, 18),
  Fibroblast = c(0, 0, 1, 1, 158, 280)
)
rownames(X_heldout) <- genes

true_props <- rbind(
  mix_immune_rich = c(T_cell = 0.60, Monocyte = 0.30, Fibroblast = 0.10),
  mix_stroma_rich = c(T_cell = 0.25, Monocyte = 0.25, Fibroblast = 0.50)
)
bulk_syn <- X_heldout %*% t(true_props) * 1000

fit_nnls <- function(X, y, weights = rep(1, nrow(X))) {
  Xw <- X * sqrt(weights)
  yw <- y * sqrt(weights)
  opt <- optim(rep(1 / ncol(X), ncol(X)),
               function(b) sum((yw - as.vector(Xw %*% b))^2),
               method = "L-BFGS-B", lower = rep(0, ncol(X)))
  setNames(opt$par / sum(opt$par), colnames(X))
}

est_unweighted <- t(apply(bulk_syn, 2, function(y) fit_nnls(X_ref, y)))
est_weighted   <- t(apply(bulk_syn, 2, function(y) fit_nnls(X_ref, y, w_inv_var)))
cat(sprintf("MAE unweighted=%.4f | MAE weighted=%.4f\n",
            mean(abs(est_unweighted - true_props)),
            mean(abs(est_weighted - true_props))))
print(round(est_weighted, 3))

# Fit an immune-only reference to a bulk mixture containing 45% unmodeled tumour RNA:
tumour_profile <- c(CD3D = 0, TRBC1 = 0, LYZ = 4, S100A8 = 6, COL1A1 = 22, STRESS_VAR = 190)
bulk_tumour <- (0.35 * X_heldout[, "T_cell"] + 0.20 * X_heldout[, "Monocyte"] + 0.45 * tumour_profile) * 1000
est_omitted <- fit_nnls(X_ref[, c("T_cell", "Monocyte")], bulk_tumour, w_inv_var)
print(round(est_omitted, 3))

MAE unweighted=0.1227 | MAE weighted=0.0036
                T_cell Monocyte Fibroblast
mix_immune_rich  0.607    0.297      0.096
mix_stroma_rich  0.253    0.251      0.496
  T_cell Monocyte
   0.614    0.386

Notice both diagnostic lessons: when STRESS_VAR spikes in held-out fibroblasts (mix_stroma_rich, true T_cell = 0.250, Fibroblast = 0.500), unweighted NNLS misassigns the stress signal (T_cell = 0.526, Fibroblast = 0.275, MAE = 0.1227), whereas inverse cross-donor variance weighting recovers 0.253, 0.251, 0.496 (MAE = 0.0036). Equally important, when 45% of the bulk RNA comes from an unrepresented malignant population, the two-population immune fit reports T_cell = 0.614, Monocyte = 0.386 (summing cleanly to 1.000 despite missing nearly half the tissue).

Solid-tumour bulk RNA-seq: malignant heterogeneity, purity, and BayesPrism

Deconvolving bulk solid-tumour cohorts (such as TCGA or clinical biopsy trials) poses a specific challenge: non-malignant immune and stromal lineages share conserved transcriptional programs across patients, whereas malignant epithelial or glial cells harbour patient-specific aneuploidy and oncogenic programs that rarely match a single reference donor. When deconvolving tumour bulk RNA-seq:

  • Never use a healthy PBMC or normal-organ reference without accounting for the malignant compartment; otherwise tumour transcripts inflate epithelial, myeloid, or cycling immune estimates.
  • Compare tumour cell-fraction estimates against independent DNA-based tumour purity (ABSOLUTE, ASCAT, sequenza, or pathology slide review) when matched WES/WGS or H&E slides exist.
  • Consider Bayesian tumour-specialized frameworks such as BayesPrism (Chu et al., 2022), which models conserved non-malignant states jointly while updating a patient-specific malignant expression prior, or CIBERSORTx (Newman et al., 2019) when cross-platform batch correction (S-mode / B-mode) is required.

Hypothetical decision check

Imagine a hypothetical fit that reports proportions summing to one across the cell types included in the reference, while a population of interest is not represented there. Does the sum show that the reported fractions are validated tissue proportions?

Reasoned feedback

No. The estimates are conditional on the included reference types, and normalization to one does not show that the reference is exhaustive or that the fit is accurate. An omitted population can make the reported mixture ambiguous. Review reference coverage and fit diagnostics, test stability under defensible reference choices, and compare with an independent measurement from the same samples when available.

When estimates look implausible

Check gene-ID overlap and order, input scale (linear/raw counts vs log-transformed values; see Avila Cobos et al., 2020), missing or mislabelled metadata, reference coverage, and whether multiple reference profiles are too similar to distinguish. Examine MuSiC's fit and variance outputs alongside the proportions. Do not clip, renormalize, or discard unexpected estimates without understanding what produced them.

Analysis record to keep

For each run, record the reference tissue and condition, cell-type and donor fields, preprocessing and expression scale, number of shared genes, included cell types, MuSiC version, output dimensions, weighted-vs-NNLS stability differences, and any pseudo-bulk or orthogonal purity validation.
