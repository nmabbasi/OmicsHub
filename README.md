## 📋 Overview
The **Bioinformatics Workflow Hub** (formerly S2R) is a comprehensive educational documentation portal designed to bridge the technical gap between High-Performance Computing (HPC) Bash environments and R-based data analysis workflows. 

It specifically focuses on empowering researchers to master the end-to-end computational biology pipeline, heavily emphasizing **single-cell RNA-sequencing (scRNA-seq)** data analysis.

## 🗂️ Core Content & Tutorials
This repository hosts the source code for the interactive web portal, featuring step-by-step guides on:
- **HPC Fundamentals:** Visual guides (via MobaXterm/SSH) on navigating cluster environments, resource allocation, and managing software environments using Conda.
- **Shell to R Transitions:** Seamless workflows demonstrating how to transition raw sequencing data (processed in Linux/Shell) into robust statistical analysis frameworks (processed in R).
- **scRNA-seq Mastery:** Dedicated tutorials on processing, quality control, dimensional reduction, and differential expression analysis of single-cell datasets.
