CHOOSE ONE LANGUAGE AFTER THE FOUNDATIONS

Start with R + R Markdown.

R and R Markdown make a clear first route from analysis to a reproducible report. Python is a fully supported alternative if it better fits your lab or tools. You do not need to learn both.

RECOMMENDED START

R + R Markdown

Begin with R and Tidyverse, then try the runnable R Markdown reporting exercise using synthetic QC values.

Start with R and Tidyverse → Try the R Markdown reporting exercise →
ALTERNATIVE ROUTE

Python

Choose Python instead when your group, collaborators, or preferred tools use it. It is an equivalent route, not an extra prerequisite.

Start with Python →

Both routes meet again at shared foundations: statistics and study design.

Good habit: Take time to understand each command and check what it changes. Avoid copying commands you cannot explain.

BEFORE YOU INSTALL ANYTHING

A few practical checks, then choose your pace.

Start small. Requirements depend on the lesson, software, and size of your data.

01COMPUTING

What computer do I need?

A modern laptop is enough for many foundation exercises.

Check resource needs

Check the chosen lesson's operating-system and memory requirements. Needs vary with the tools and input size.

Larger analyses may need HPC or other high-memory computing. Estimate memory, storage, threads, and runtime for the actual data and tools. Follow your institution's scheduler policies.

02SOFTWARE

What should I install?

Install only what your chosen lesson asks for.

See common tools

Follow each lesson's versions and dependencies. The collection is not standardized on one Python or R version. Record your environment and check compatibility.

  • Package managersMamba, Micromamba
  • Recommended languageR (Tidyverse, Seurat, DESeq2)
  • Alternative languagePython (Scanpy, Biopython)
  • Optional workflowsSnakemake, Nextflow, Docker, Singularity
03PRACTICE

Expected Outcomes

Build the habit of planning, adapting, and checking reproducible analysis.

Try a first milestone

Complete the Command-Line Part 1 lab. Make a practice project tree, safely copy and move files, and inspect the named zero-byte placeholders. They are not sequencing data.

Check the displayed paths and file sizes. The lesson explains what each output verifies and what it cannot establish. Practice templates are not research findings.
