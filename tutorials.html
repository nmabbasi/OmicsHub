What do the learning-format labels mean?
Hands-on lab
Follow a bounded exercise using supplied fixtures or a stated public-data route, then inspect its outputs.
Conceptual guide
Understand scientific choices, assumptions, and interpretation; runnable code is not the main outcome.
Advanced template
Adapt code and setup to compatible inputs and your own environment, then check the outputs.
Reference
Look up formats, commands, or troubleshooting checks.

These labels describe the learning format, not validation status. Not every biological workflow has been run end to end. Check the lesson’s prerequisites and outputs; a teaching example is not a validated research or clinical pipeline.
