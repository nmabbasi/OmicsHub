Pseudobulk DE Analysis

NM

Nasir Mahmood Abbasi, PhD

Bioinformatics Educator

Example environment: R 4.3.2 (Seurat v5.0.1, DESeq2 1.42.0)

Learning objectives and prerequisites

You will learn: how to convert single-cell RNA-seq (scRNA-seq) counts into sample-level "pseudobulk" counts and run a statistically valid differential expression (DE) analysis using DESeq2. You will also learn how to inspect DESeq2 output, generate diagnostic plots (MA/PCA/Volcano), and interpret what the results do—and do not—prove.

Prerequisites: an R environment with Seurat (v4 or v5), DESeq2, and tidyverse/ggplot2 installed; a processed Seurat object containing cells from multiple biological replicates (patients/samples) and appropriate per-cell metadata fields for sample ID and cell type. Example R version: 4.3.x. This tutorial assumes you have already performed preprocessing (QC, normalization, clustering) and cell-type annotation.

Why pseudobulk matters (biological & statistical context)

Single-cell assays produce counts at the level of individual cells, but biological inference about experimental conditions (for example, disease vs control) must be based on independent biological replicates (patients, animals, or samples). Treating each cell as an independent replicate inflates the effective sample size and dramatically increases false positives because cell-to-cell variation (technical and biological) is not the same as variation between patients.

Pseudobulk is a pragmatic and widely accepted approach: aggregate raw counts across cells of the same cell type within each biological sample to create one count vector per sample per cell type. The resulting matrix (genes × samples) can be analyzed with established bulk RNA-seq DE tools (DESeq2, edgeR, limma-voom) that correctly model between-sample variance. This restores the statistical unit of inference to the true biological replicate.

Reproducible workflow (step-by-step)

Inputs you need:

  • A Seurat object file: e.g. /data/seurat_objects/pbmc_processed.rds
  • Per-cell metadata fields within that object: patient_id (or sample_id) and cell_type (or cluster/annotation).
  • Raw (unnormalized) counts stored in the Seurat object assay (commonly RNA counts).

Outputs produced by this workflow:

  • Pseudobulk count matrix CSV: e.g. /output/pseudobulk/cd4_pseudobulk_counts.csv
  • DESeq2 results table CSV: e.g. /output/deseq2/cd4_DE_results.csv
  • Diagnostic plots: MA-plot, PCA, and Volcano saved as PNG files in /output/plots/

1) Load libraries and data

# Example: R script pseudobulk_dge.R
library(Seurat)       # Seurat v4/v5
library(DESeq2)       # DESeq2 from Bioconductor
library(ggplot2)
library(dplyr)
library(readr)

# Path to your Seurat object (replace with your real path)
seurat_file <- "/data/seurat_objects/pbmc_processed.rds"
seurat_obj <- readRDS(seurat_file)

Confirm the metadata fields exist:

# Check metadata columns (must include patient/sample id and cell type)
head(seurat_obj@meta.data)
# e.g. columns: cell, patient_id, disease_state, cell_type

2) Subset to the cell type of interest and aggregate to pseudobulk

The following aggregates raw counts across cells grouped by sample (patient_id) and disease state. We will create group IDs like Sample01_Healthy so it is easy to inspect column names in downstream steps.

# Subset to cell type (example: CD4 T cells)
cell_type_of_interest <- "CD4 T"
subset_obj <- subset(seurat_obj, idents = cell_type_of_interest)

# Ensure raw counts exist (assay "RNA" and slot "counts")
counts <- GetAssayData(subset_obj, assay = "RNA", slot = "counts")

# Create a combined group id: sample_patient + disease_state
metadata <- subset_obj@meta.data %>%
  dplyr::mutate(group_id = paste0(patient_id, "_", disease_state))

# Aggregate counts by group_id using Seurat helper: returns a list of matrices per assay
pb_list <- AggregateExpression(subset_obj, group.by = "group_id", assays = "RNA", slot = "counts", return.seurat = FALSE)
pseudobulk_counts <- pb_list$RNA   # matrix: genes x group_id
# Save pseudobulk counts
dir.create("/output/pseudobulk", recursive = TRUE, showWarnings = FALSE)
readr::write_csv(as.data.frame(pseudobulk_counts) %>% tibble::rownames_to_column("gene"),
                 "/output/pseudobulk/cd4_pseudobulk_counts.csv")

Notes:

  • AggregateExpression sums raw counts by default. Do not sum normalized or scaled data for pseudobulk.
  • Confirm that each group_id corresponds to exactly one biological sample (no mixing of multiple patients into one id).

3) Prepare DESeq2 inputs and run analysis

# Build colData for DESeq2 using the column names of pseudobulk_counts
colnames(pseudobulk_counts)
# You should see names like "Sample01_Healthy", "Sample02_CTCL", ...

# Construct metadata for samples: parse patient and condition
sample_names <- colnames(pseudobulk_counts)
coldata <- tibble::tibble(sample = sample_names) %>%
  dplyr::mutate(
    patient = sub("_.*$", "", sample),
    condition = sub("^[^_]*_", "", sample)
  ) %>%
  dplyr::select(sample, patient, condition) %>%
  tibble::column_to_rownames("sample")

# Ensure rownames of coldata match colnames of counts
all(rownames(coldata) == colnames(pseudobulk_counts))  # should be TRUE

# Create DESeqDataSet
dds <- DESeqDataSetFromMatrix(countData = pseudobulk_counts,
                              colData = coldata,
                              design = ~ condition)   # simple design; expand for covariates

# Optional filtering: remove genes with very low counts across all samples
keep <- rowSums(counts(dds)) >= 10  # adjust threshold for cohort size
dds <- dds[keep, ]

# Run DESeq2 pipeline
dds <- DESeq(dds)

# Retrieve results: contrast condition CTCL vs Healthy (replace labels as needed)
res <- results(dds, contrast = c("condition", "CTCL", "Healthy"), alpha = 0.05)
res_ordered <- res[order(res$padj), ]
# Save table
dir.create("/output/deseq2", recursive = TRUE, showWarnings = FALSE)
write.csv(as.data.frame(res_ordered), "/output/deseq2/cd4_DE_results.csv", row.names = TRUE)

What each command produces:

  • pseudobulk_counts: an R matrix saved to CSV containing summed raw counts per gene per sample (genes × samples).
  • dds: a DESeqDataSet that contains design, counts, and sample metadata; filtered to remove near-zero genes.
  • res_ordered: DESeq2 results object (log2 fold changes, p-values, adjusted p-values) saved to CSV.

4) Diagnostics and plotting (PCA, MA, Volcano)

# Variance stabilizing transformation for plotting
vsd <- vst(dds, blind = TRUE)   # vst = variance stabilizing transform

# PCA plot and save
pca_df <- as.data.frame(assay(vsd)) %>%
  t() %>%
  as.data.frame() %>%
  tibble::rownames_to_column("sample") %>%
  left_join(coldata %>% tibble::rownames_to_column("sample"), by = "sample")

pca_res <- prcomp(t(assay(vsd)))
pca_plot <- ggplot(data = data.frame(pca_res$x), aes(x = PC1, y = PC2, label = rownames(pca_res$x))) +
  geom_point(aes(color = coldata$condition), size = 3) +
  labs(title = "PCA of pseudobulk samples (VST-transformed)")

ggsave("/output/plots/pca_pseudobulk.png", pca_plot, width = 6, height = 4)

# MA-plot
png("/output/plots/ma_plot.png", width = 800, height = 600)
plotMA(res, main = "MA-plot: CTCL vs Healthy", ylim = c(-5, 5))
dev.off()

# Volcano plot
res_df <- as.data.frame(res) %>% tibble::rownames_to_column("gene")
res_df <- res_df %>% mutate(significant = (!is.na(padj)) & padj < 0.05 & abs(log2FoldChange) > 1)

volcano <- ggplot(res_df, aes(x = log2FoldChange, y = -log10(pvalue))) +
  geom_point(aes(color = significant), alpha = 0.6) +
  scale_color_manual(values = c("grey", "red")) +
  labs(title = "Volcano plot: CTCL vs Healthy", x = "log2 fold change", y = "-log10(p-value)") +
  theme_minimal()
ggsave("/output/plots/volcano.png", volcano, width = 6, height = 4)

Output inspection and interpretation

Key columns on DESeq2 output to inspect:

  • baseMean — average normalized count across samples for the gene.
  • log2FoldChange — estimated magnitude of change between conditions (positive means up in the numerator of the contrast).
  • stat, pvalue, and padj — test statistic and multiple-test-corrected p-value (Benjamini–Hochberg FDR).

What to look for:

  • Large |log2FoldChange| combined with small adjusted p-value (e.g. padj < 0.05) suggests a robust change across biological replicates.
  • Genes with very low baseMean may have unstable fold-change estimates; treat those cautiously.
  • PCA should show separation by biological condition if condition explains a major axis of variation. If PCA shows clustering by batch, sample preparation, or sequencing run, this indicates confounding.

What a plausible result means—and does not mean:

  • Significant DE genes are candidate differences between the biological groups you compared; they are not proof of mechanism or causation.
  • Results are only as reliable as your experimental design: insufficient biological replicates, confounding covariates, or unequal sample composition can bias results.
  • Pseudobulk limits inference to differences at the sample level for the chosen cell type; changes in cell-type composition across samples are not captured here (you would need complementary compositional analysis).

Troubleshooting: symptoms, likely causes, and fixes

  • Symptom: Nearly every gene has an extremely low adjusted p-value (lots of seemingly significant hits).
    Likely cause: You aggregated cells but inadvertently used cell-level metadata as replicates (e.g., using cell barcodes instead of patient IDs), or you used normalized data for aggregation.
    Fix: Confirm that group_id is one column per biological sample. Re-aggregate using raw counts (not log-normalized or scaled counts). Ensure design addresses sample-level covariates.
  • Symptom: PCA shows samples clustering by sequencing batch, not by condition.
    Likely cause: Batch effects are present and not modeled.
    Fix: Add batch as a covariate in the DESeq2 design (e.g. design = ~ batch + condition) if batches are balanced with respect to condition. Consider ComBat-Seq or removeBatchEffect for visualization only; do not remove biological signal.
  • Symptom: Warning about zero-inflation or convergence in DESeq2.
    Likely cause: Very small sample size (few biological replicates) or many genes with near-zero counts.
    Fix: Increase number of biological replicates if possible; filter out genes with very low counts before testing; consider using limma-voom with robust options for very small groups.
  • Symptom: Unexpected direction of log2 fold-change (sign reversed).
    Likely cause: Contrast order in results() matters (contrast = c("condition", "CTCL", "Healthy") returns log2(CTCL/Healthy)).
    Fix: Verify the order passed to results() and interpret positive values as higher in the first level of the contrast.

Limitations, version and reference-data caveats, and responsible use

Limitations:

  • Pseudobulk removes cell-to-cell variability that may be biologically informative (e.g., expression heterogeneity within a sample). It provides sample-level estimates for a given annotated cell type.
  • Small numbers of biological replicates (n ≤ 3 per group) limit power and inflate uncertainty. Statistical tests will be poorly behaved with very few samples.
  • Cell-type misannotation or variable cell-type composition between samples can bias pseudobulk results—ensure consistent cell-type definitions and consider subsampling or weighting strategies if sample cellularity differs widely.

Version and reference-data caveats:

  • Different versions of Seurat and DESeq2 may change function signatures or default behaviors (e.g., AggregateExpression arguments). Test code on a small mock dataset after updating packages.
  • When using gene annotation for downstream reporting and enrichment, ensure consistent gene identifiers (ENSEMBL vs gene symbol) and the reference genome build used in preprocessing.

Responsible use:

  • Do not overinterpret single-gene hits as clinical biomarkers without independent validation (technical replication, orthogonal assays, and independent cohorts).
  • Document sample inclusion/exclusion criteria, preprocessing steps, and analytical choices (filter thresholds, design formula) so analyses are reproducible and transparent.

Next-step checklist (concise)

  1. Confirm pseudobulk matrix columns correspond to unique biological samples and correct condition labels.
  2. Filter low-count genes and run DESeq2 with an appropriate design (add batch/covariates if needed).
  3. Inspect PCA and MA plots for confounding signals; revisit design if batch effects appear.
  4. Save and review the top DE genes; validate a small set by orthogonal experiments or an independent cohort.
  5. Complement pseudobulk DE with compositional analysis across cell types and pathway/enrichment tests on DE gene sets.
