START HERE

You have the biology.
We'll teach you the tools.

You don't need to know a programming language or any tool names yet. This page will guide you step by step from your first terminal command to analyzing your own sequencing data.

Start your first lesson → See the learning path ↓

WHO THIS IS FOR

Is this for me?

You do not need to arrive with code or software experience. You only need a biological question worth investigating.

THE FOUNDATION

Master these four skills first.

Complete them in order. Each one builds on the last. When you're done, you'll be ready to work with real biological data on any high-performance cluster.

01

Understand the Workflow

Learn what bioinformatics is, how data flows from sequencer to results, and how a reproducible pipeline is structured.

Start → 02

Learn the Command Line

Navigate folders, create files, and run tools from the terminal, the language every bioinformatics tool speaks.

Start → 03

Install Software Safely

Use Conda and Mamba to create isolated environments. Never break your system by installing incompatible tools again.

Start → 04

Use a Supercomputer

Connect to an HPC cluster, submit jobs, and run analyses that are too large for a laptop.

Start →
💡 Tip: Work slowly enough to actually understand what each command does. Don't just copy and paste!
