ROADMAP & REQUIREMENTS

Prerequisites, Setup & Learning Outcomes

Everything you need to know before running your first command, how to configure your computational environment, and how to verify your mastery at each phase.

01

Hardware Requirements

For foundational data wrangling, R scripting, and small count matrix tutorials, any modern laptop (macOS, Ubuntu Linux, or Windows 10/11 with WSL2) with at least 8 GB of RAM is sufficient.

HPC Requirement: For large BAM alignments, WES variant calling, and full-resolution spatial transcriptomics, access to a university or institutional Slurm HPC cluster with 32+ GB RAM is recommended.
02

Software Stack

We prioritize reproducibility above all. All tutorials are standardized on Python 3.11+ and R 4.3+ within isolated virtual environments to prevent library conflicts.

  • Package Managers: Mamba / Micromamba (faster than default Conda)
  • Core Languages: Python (Scanpy, Biopython), R (Seurat, DESeq2)
  • Orchestration: Snakemake, Nextflow, Docker & Singularity
03

Expected Outcomes

By following this curriculum, wet-lab researchers gain complete computational autonomy, transforming from copying code snippets to writing reliable, reproducible analysis pipelines.

Key Milestone: Ability to take raw FASTQ or count matrices directly from the sequencer, perform strict mathematical QC, and produce publication-grade figures.

Dr. Abbasi's Advice: How to Assess Your Progress

When students in our lab at the Bordeaux Institute of Oncology (BRIC INSERM) begin computational research, I always emphasize that true mastery is not memorizing syntax, it is understanding your data and knowing how to troubleshoot when something breaks. Ask yourself these three checkpoint questions as you move through our modules:

Checkpoint 1: Environment Integrity

Can you build a clean, isolated virtual environment from a YAML specification file and guarantee that someone on another workstation can run your code without package mismatch errors?

Checkpoint 2: Resource Allocation

Can you estimate walltime, thread count, and RAM requests in your Slurm job script accurately, avoiding both out-of-memory kills and excessive cluster queue wait times?

Checkpoint 3: Biological Interpretation

Can you inspect your diagnostic QC plots (FastQC, doublet frequencies, mitochondrial percentage, or LISI scores) and explain why a filtering cutoff is mathematically justified for your biological cohort?
