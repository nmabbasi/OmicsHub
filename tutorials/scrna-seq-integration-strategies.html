scRNA-seq Integration: Harmony, RPCA, and CCA

NM

Nasir Mahmood Abbasi, PhD

Bioinformatics Educator

Worked example updated 23 October 2026.

When you combine single-cell RNA-seq libraries across sequencing chemistries, donors, or labs, the same cell type often splits into separate clusters by batch rather than biology. Integration algorithms align shared cell states across batches so you can cluster and annotate them together, without merging distinct or batch-unique populations.

What you will do (Hands-on lab, ~30 min): Compare unintegrated PCA against Harmony on 1,149 public PBMC query cells sequenced with 10x Chromium v2 and v3, measure batch mixing (iLISI) and cell-type purity (cLISI) in 20-dimensional space, and inspect a rare batch-unique population where integration creates false mixing.

Prerequisites and scope: Assumes familiarity with single-cell normalization and PCA and cell-type annotation. The PCA to Harmony workflow and LISI metrics were executed in R for this lesson with downloadable scripts and outputs; Seurat v5 RPCA, CCA, and scVI/scANVI are covered as unexecuted comparison guides.

1. Design the comparison and inspect batch balance

A batch effect is systematic variation introduced by technical factors (such as library chemistry, capture lane, or sequencing depth) rather than cell identity. Before running any correction tool, verify that your batches share comparable cell types and record how many cells each batch contributes to each population.

This lab uses the public pbmcsca.SeuratData 3.0.0 PBMC dataset from SeuratData, published by Ding et al. (2020). The two query batches are genuine library-chemistry groups, 10x Chromium (v2) A and 10x Chromium (v3), rather than an artificial split of one count matrix. A third group (10x Chromium (v2) B) is held out as the reference for the annotation tutorial and never enters this integration run.

The script keeps cells with more than 200 detected genes and valid supplied CellType labels (excluding empty, Unknown, or Unassigned), then samples up to 80 cells per (Method, CellType) stratum with seed 20261023. Smaller strata are kept whole. Capping prevents abundant monocytes and CD4+ T cells from dominating pooled medians, yielding 1,149 query cells across 9 categories (not natural blood proportions).

Why integration is a question, not an obligation: Shared cell types make cross-batch alignment possible, whereas a cell state restricted to one batch has no cross-batch counterpart to align. Always check your batch-by-cell-type counts first: forcing a batch-unique population to mix with another batch pulls it into unrelated cell types (overcorrection).

Why Harmony adjusts PCA coordinates instead of RNA counts

Harmony (Korsunsky et al., 2019) operates in low-dimensional PCA space rather than altering the gene expression matrix. It alternates between two steps: grouping cells into soft clusters with a batch-diversity penalty, then computing linear ridge-regression offsets per centroid to shift batch-specific cells closer together.

# Excerpt from run_example.R: Harmony 1.2.3 on 20 unintegrated PCs
query_harmony <- harmony::RunHarmony(
  object = query,
  group.by.vars = "batch",
  reduction.use = "pca",
  dims.use = 1:20,
  theta = 2,
  lambda = 1,
  max_iter = 10,
  ncores = 1
)
  • theta = 2 sets the soft-cluster diversity penalty. Raising theta pushes batches to mix more aggressively, increasing the risk of merging batch-unique or disease-restricted states into unrelated clusters.
  • lambda = 1 sets the ridge-regression penalty that shrinks batch correction offsets, guarding against overcorrection when a cluster is dominated by one batch.
  • max_iter = 10 caps optimization rounds (Harmony 1.2.3 and newer 2.x releases use max_iter, whereas older pre-1.0 versions used max.iter.harmony).

Keep raw RNA counts untouched for downstream expression tests: Integration creates aligned coordinates for clustering and neighbor graphs, not biological replicates or batch-corrected gene counts. In run_example.R, an explicit check verifies that the raw RNA counts before and after RunHarmony() are identical. Always run differential expression on the uncorrected RNA assay using a sample-aware design.

3. Score batch mixing and label purity in 20D space

Visual UMAP overlap can mislead because UMAP warps global distances and changes layout across random seeds. To measure integration quantitatively, we use lisi::compute_lisi() (Local Inverse Simpson's Index) directly on the 20-dimensional PCA and Harmony embeddings, never on 2D UMAP coordinates.

With perplexity = 30, LISI builds a Gaussian kernel over roughly 3 * perplexity = 90 nearest neighbors per cell (meaning you need at least 91 cells) and reports the effective number of categories present in that local neighborhood. Before scoring, the script enforces exact row-order and missingness invariants so every cell in PCA pairs 1-to-1 with the same cell in Harmony.

# Invariants checked in run_example.R before paired scoring
stopifnot(identical(rownames(pca_coordinates), rownames(harmony_coordinates)))
stopifnot(identical(rownames(pca_coordinates), rownames(evaluation_metadata)))
stopifnot(!anyNA(evaluation_metadata[, c("batch", "source_label")]))

pca_lisi <- lisi::compute_lisi(
  pca_coordinates, evaluation_metadata,
  label_colnames = c("batch", "source_label"), perplexity = 30
)
harmony_lisi <- lisi::compute_lisi(
  harmony_coordinates, evaluation_metadata,
  label_colnames = c("batch", "source_label"), perplexity = 30
)
Two LISI metrics answer two opposite questions
Diagnostic How to read the value here What it does not prove
Batch iLISI (integration LISI) Ranges from 1 (local neighborhood dominated by one batch) toward 2 (equal local mix of both batches). Higher is better only when cell types are shared. A universal target of 2, removal of causal technical artifacts, or permission to mix batch-unique populations.
Source-label cLISI (cell-type LISI) Ranges from 1 (pure single cell-type neighborhood) upward when distinct cell types mix. Values near 1 mean label structure is preserved. Independent biological ground truth, correct initial annotations, or preservation of continuous trajectories and rare subtypes.

The supplied source_label annotations come from the original study's expression-based labeling (not clusters newly derived from Harmony), which makes them useful as a consistency check rather than an independent gold standard. Additional conservation metrics such as silhouette width are covered in the follow-up integration QC tutorial.

4. Inspect the observed comparison and rare-subset slice

Saved run summary: Scoring the exact same 1,149 query cells in 20D PCA and 20D Harmony raises median batch iLISI from 1.066 to 1.918 while keeping median source-label cLISI near 1 (1.016 to 1.008).

Observed raw LISI scores across 1,149 query cells: median [25th-75th percentile]
Representation Cells Batch iLISI Source-label cLISI
PCA (unintegrated baseline) 1,149 1.066 [1.011-1.257] 1.016 [1.001-1.140]
Harmony (theta = 2, lambda = 1) 1,149 1.918 [1.789-1.979] 1.008 [1.000-1.091]
Paired per-cell delta (Harmony minus PCA) 1,149 +0.766 [0.484-0.912] -0.003 [-0.031-0.000]

Notice that the paired per-cell median delta in batch iLISI is +0.766, whereas subtracting the pooled medians gives 1.918 - 1.066 = 0.852, because each cell starts from its own neighborhood baseline. Paired medians and interquartile ranges (IQR) measure within-cell change without inflating significance through cell-level p-values (cells from one library are pseudoreplicates, not independent donors).

Slice the scores by source label to catch hidden overcorrection

A pooled median can hide failure on a small cell type. The bundle saves per-cell scores, per-label summaries, and paired cell-level differences. You can reproduce the per-label paired median check locally with standard-library Python 3:

import csv, statistics

groups = {}
with open("observed/lisi_paired_differences.csv", newline="", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        groups.setdefault(row["source_label"], []).append((
            float(row["delta_iLISI_batch_Harmony_minus_PCA"]),
            float(row["delta_cLISI_source_label_Harmony_minus_PCA"]),
        ))

for label, vals in sorted(groups.items()):
    di = statistics.median(v[0] for v in vals)
    dc = statistics.median(v[1] for v in vals)
    print(f"{label:28s} n={len(vals):3d}  med_d_iLISI={di:+.3f}  med_d_cLISI={dc:+.3f}")

The table reveals three distinct outcomes:

  1. Balanced shared lineages gain mixing: CD16+ monocyte and B cell move from batch-separated to well-mixed while keeping cLISI at 1.000.
  2. Already-mixed lineages shift modestly: Megakaryocyte (29 v2 A, 41 v3) starts near 1.689 iLISI in PCA and shifts by +0.174.
  3. Batch-unique rare subsets lose purity: All 26 plasmacytoid dendritic cells (pDCs) come from v2 A (0 from v3). With no v3 pDCs within perplexity = 30, raising pDC iLISI pulls those 26 cells toward unrelated v3 types, worsening cLISI from 1.360 to 1.529 (paired delta +0.073).

5. Decide whether to accept, tune, or reject

Treat LISI metrics as exploratory screening diagnostics rather than independent biological validation. Combine batch counts, per-label iLISI/cLISI changes, and raw RNA marker inspection before accepting an integrated embedding for clustering.

  • Batch iLISI rises while source-label cLISI stays near 1: Consistent with aligned shared populations. Still verify canonical RNA markers (as shown in the annotation lesson's marker audit) on the untouched RNA assay.
  • Batch iLISI and source-label cLISI both rise: Warning sign of overcorrection (as seen in the 26 v2-A-only pDCs), label errors, or transitional states being collapsed. Lower theta (for example, compare theta = 1 vs. theta = 2), increase lambda, or switch to a more conservative anchor method such as RPCA.
  • Batch iLISI barely changes from baseline: Either the populations already mix (like megakaryocytes here), or the batch covariate you supplied is not driving the separation. Inspect donor, QC depth, and cell-cycle effects before increasing correction strength.
  • A small population shifts into a larger cluster: Check its batch-by-label counts first. If it exists in only one batch or condition, inspect its defining markers in unintegrated PCA and raw counts rather than trusting the integrated UMAP.

Practice: retain, investigate, or reject?

Pick one source-label category from the table above. Record its counts in v2 A and v3, its PCA-to-Harmony iLISI and cLISI medians, and make a retain, investigate, or reject decision for joint clustering. State what raw-RNA evidence would change your decision, without using cell-level scores to claim population-level significance.

Check worked example reasoning (CD16+ monocyte vs. Plasmacytoid dendritic cell)

CD16+ monocyte (Retain for joint clustering): Balanced counts (80 in v2 A, 80 in v3); batch iLISI rises from 1.004 to 1.929 (paired median +0.888) while cLISI holds at 1.001 -> 1.000. I would check FCGR3A/MS4A7/LYZ in the uncorrected RNA assay across both batches to confirm both groups express the expected monocyte markers; only discordant marker loss or subcluster collapse would overturn this decision.

Plasmacytoid dendritic cell (Investigate / do not rely on integrated neighborhood alone): Unbalanced counts (26 in v2 A, 0 in v3); iLISI rises slightly (1.261 -> 1.366) while cLISI worsens from 1.360 to 1.529 (paired median +0.073). Because v3 has zero pDCs, mixing here pulls v2 A pDCs toward non-pDC neighbors. I would inspect canonical pDC markers (LILRA4, IL3RA, CLEC4C) in uncorrected space and test theta = 1 or conservative RPCA before clustering.

6. Choose among Harmony, RPCA, CCA, and scVI/scANVI

Seurat v5 RPCA, Seurat v5 CCA, scVI, and scANVI were not executed on this 1,149-cell subset. The comparison below summarizes their documented behavior in Seurat v5, scvi-tools, and the scIB benchmark (Luecken et al., 2022) to help you choose the right family for your own dataset.

Comparison of major scRNA-seq integration method families
Method family Input and corrected output Scaling and compute When to choose and primary failure mode
Harmony (harmony::RunHarmony or HarmonyIntegration) Takes unintegrated PCA; returns corrected low-dimensional coordinates (counts unchanged). Very fast; scales to 105-106 cells on CPU. Strong default baseline for routine donor/lane batches. High theta can pull batch-unique or disease-restricted subsets into unrelated clusters.
Seurat v5 RPCA (RPCAIntegration) Projects split log-normalized or SCTransform (SCT) layers into each other's PCA space to find reciprocal anchors; returns an integrated reduction. Fast and memory-efficient across many samples. Preferred over CCA for large cohorts, same-platform batches, or datasets with unshared cell types. More conservative, so it can under-align strong cross-chemistry or cross-species shifts.
Seurat v5 CCA (CCAIntegration) Finds canonical correlation vectors maximizing shared covariance across split layers to build anchors. Slowest; quadratic memory/runtime growth with batch count and cell number. Useful when strong technical shifts (such as scRNA-seq vs. snRNA-seq or cross-species) separate clear shared types. High overcorrection risk when batch compositions differ sharply (such as tumor vs. healthy).
scVI / scANVI (scvi-tools in Python) Deep variational autoencoder modeling raw integer UMI counts with batch covariates (plus partial cell labels in scANVI); returns latent space X_scVI / X_scANVI. Scales to millions of cells; GPU strongly recommended. Top performer on complex multi-batch atlases in scIB (especially scANVI when reliable seed labels exist). Sensitive to highly variable gene (HVG) selection, latent dimensions, and training epochs; fails if fed log-normalized counts instead of raw UMI counts.

In Seurat v5, integration runs across split layers inside one RNA assay via IntegrateLayers() (documented in the Seurat v5 integration vignette and RPCA guide). After building your neighbor graph and UMAP on the new integrated reduction, rejoin layers with JoinLayers() before running marker tests on the normalized RNA data:

# Unexecuted Seurat v5 syntax reference (not run in run_example.R)
obj[["RNA"]] <- split(obj[["RNA"]], f = obj$batch)
obj <- NormalizeData(obj)
obj <- FindVariableFeatures(obj)
obj <- ScaleData(obj)
obj <- RunPCA(obj)

# Swap RPCAIntegration for CCAIntegration or HarmonyIntegration
obj <- IntegrateLayers(
  object = obj,
  method = RPCAIntegration,
  orig.reduction = "pca",
  new.reduction = "integrated.rpca"
)

obj <- FindNeighbors(obj, reduction = "integrated.rpca", dims = 1:20)
obj <- RunUMAP(obj, reduction = "integrated.rpca", dims = 1:20, reduction.name = "umap.rpca")
obj <- JoinLayers(obj, assay = "RNA")  # Required before FindMarkers()

To benchmark any alternative fairly against this worked example, keep the exact same 1,149 query cells, 2,000 HVGs, and 20-dimensional comparison policy, align every embedding by cell ID, and re-run compute_lisi() on both the pooled set and each individual source label.

7. Common errors, fixes, and next steps

  • Error in harmony::RunHarmony(...): unused argument (max.iter.harmony = 10): Harmony 1.2.x and 2.x renamed max.iter.harmony to max_iter. Check packageVersion("harmony") and update the argument name to max_iter.
  • Error: data layers are not joined. Please run JoinLayers in Seurat v5: After IntegrateLayers(), the RNA assay still holds per-batch layers. Call obj <- JoinLayers(obj, assay = "RNA") before running FindMarkers() or extracting a combined expression matrix.
  • compute_lisi() crashes or scrambles scores across cells: LISI requires at least 3 * perplexity + 1 cells (91 cells at perplexity = 30) and exact matching row order between the embedding matrix and metadata frame. Add stopifnot(identical(rownames(emb), rownames(meta))) before scoring.
  • run_example.R stops with Output directory is not empty: The script refuses to clobber existing results by default. Point --output to a fresh directory or pass --force to refresh managed output files cleanly.
  • scVI raises a count-type warning or produces poor mixing: Verify that SCVI.setup_anndata(adata, layer="counts", batch_key="batch") points to raw integer UMI counts, never log-normalized floats.

Next steps

  • Deepen metric checks: Measure silhouette width alongside LISI in scRNA-seq Integration QC: LISI and Silhouette.
  • Verify cluster markers: Inspect raw RNA markers on these same cells in Choosing and Checking Cell-Type Annotations.
  • Run sample-aware DE: Keep raw counts separate from integrated embeddings and follow Single-Cell RNA-seq Downstream Analysis.

Author's lab note: The biggest mistake I see in multi-sample cohorts is cranking up integration strength until every batch looks uniformly blended on a UMAP. In disease datasets, that often merges patient-specific tumour states or small plasmacytoid dendritic / cycling subsets into unrelated clusters. Before trusting a "well-mixed" embedding, I always inspect condition-restricted markers in uncorrected space and verify small populations individually with per-label cLISI.
