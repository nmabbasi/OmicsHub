HOW TO FOLLOW THE ACADEMY

Work through one clear agenda.

Open one lesson, run the example, and keep the output. When the step feels familiar, continue to the next line. You do not need to complete the full catalogue before choosing a data route.

STEP 01

Learn the language of bioinformatics

Start with the ideas behind data, file formats, biological questions, and reproducible analysis.

STEP 02

Make basic navigation automatic

STEP 03

Create a stable software environment

Use Conda or Mamba before installing analysis tools, so your work can be repeated later.

STEP 04

Move from your computer to compute

Connect to HPC and learn the foundations of running a larger analysis responsibly.

Connect to HPC →

A simple rule: work slowly enough to understand the output. A small completed practice project is more useful than a long list of unread tutorials.

When you reach the final step, choose one pathway and use the same core habits again.
