1

Orientation & Foundations

Build the mental model, data literacy, programming, statistics, and reproducibility skills needed before the command line and omics workflows.

⏱️ Est. Time:12-18 hours
💻 Software:Web browser, terminal, Python, R, Git
🎯 Criteria:Inspect common biological files, create a reproducible project, and explain basic statistics and QC.
🛠️ Capstone:Create a documented mini-project with a validated input, QC plot, README, and Git history.
✅ Exit Assess:Complete the foundation checklist and explain every file, decision, and output.
Computer and Data Fundamentals Biological Data Formats Quality Control Fundamentals Git and GitHub Python Fundamentals R and Tidyverse Fundamentals Statistics for Bioinformatics Experimental Design and Batch Effects Reference Genomes and Annotation Data Visualization Fundamentals Reproducible Project Structure Research Reporting and Interpretation Introduction to Bioinformatics
2

The Linux Command Line

Master the terminal, paths, permissions, pipes, grep, awk, and text processing. This is your most important tool.

⏱️ Est. Time:4-6 hours
💻 Software:Terminal (Bash/Zsh)
🎯 Criteria:Fluency in navigating directories, piping commands, and text manipulation.
🛠️ Capstone:Write a bash script to filter and summarize a GTF annotation file.
✅ Exit Assess:Script runs flawlessly on test data.
Bash Navigation & Files Data Processing & Pipes Advanced Text Processing (awk, sed)
3

Package & Environment Management

Learn how to install bioinformatics tools safely using Conda/Mamba without destroying your system.

⏱️ Est. Time:2 hours
💻 Software:Miniconda / Mamba
🎯 Criteria:Can confidently create, export, and clone isolated tool environments.
🛠️ Capstone:Deploy an exact environment from a provided YAML file.
✅ Exit Assess:Environment activates without dependency conflicts.
Conda & Mamba Environments
4

High-Performance Computing (HPC)

Learn to run large analyses on supercomputers using SSH, module loading, Slurm, and job scripts.

⏱️ Est. Time:3-4 hours
💻 Software:SSH Client, Slurm
🎯 Criteria:Ability to submit and monitor batch jobs using appropriate resource flags.
🛠️ Capstone:Submit, monitor, debug, and document a multi-core Slurm job.
✅ Exit Assess:Job completes successfully with an exit code of 0.
Connecting to the Cluster Modules & Resource Allocation Writing Slurm Job Scripts
5

Reproducible Workflows

Scale your analyses by learning workflow managers like Snakemake/Nextflow and containers like Docker/Singularity.

⏱️ Est. Time:5-8 hours
💻 Software:Snakemake / Nextflow, Docker / Singularity
🎯 Criteria:Understand workflow DAGs and containerized tool execution.
🛠️ Capstone:Build a containerized Snakemake or Nextflow workflow.
✅ Exit Assess:Pipeline runs end-to-end on test data.
Containers in Bioinformatics Snakemake & Nextflow
6

Single-Cell RNA-seq Specialization

Dive into the world of single-cell transcriptomics. Master QC, clustering, integration, and interpretation.

⏱️ Est. Time:10-15 hours
💻 Software:R, Seurat v5, ggplot2
🎯 Criteria:Mastery of the standard Seurat workflow (QC to Differential Expression).
🛠️ Capstone:Analyze a public PBMC dataset from raw matrices to annotated UMAP.
✅ Exit Assess:Produce a biologically sound annotated UMAP and marker gene list.
scRNA-seq Basics & Workflow Advanced Quality Control Data Integration Strategies Cell Type Annotation
7

Advanced Single-Cell Analysis

Go beyond basic clustering to uncover developmental pathways, cell-cell communication, and multi-modal integration.

Trajectory Inference Cell-Cell Communication CITE-seq & Multiomics Immune Repertoire (TCR/BCR)
8

Genomics & Metagenomics Specializations

Explore other critical '-omics' fields, including whole-exome sequencing and microbiome analysis.

WES Variant Calling Metagenomics Taxonomic Profiling Metagenomics Assembly Long-Read Sequencing
9

Spatial Transcriptomics & AI

The frontier of bioinformatics. Map gene expression to tissue architecture and leverage foundational AI models.

⏱️ Est. Time:15-20 hours
💻 Software:R, Python, CellTypist, LIANA, inferCNV
🎯 Criteria:Ability to execute specialized multi-omic and receptor analyses.
🛠️ Capstone:Deconvolute bulk RNA-seq using an scRNA-seq reference.
✅ Exit Assess:Accurate cell fraction estimation across patient samples.
Spatial Transcriptomics Workflows Spatial Deconvolution Strategies Foundation AI Models (scGPT, Geneformer)
