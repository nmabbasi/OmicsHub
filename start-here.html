LATER, WHEN YOU NEED IT

Follow your biological question.

These are optional routes, not extra prerequisites. Open the topic that fits your data.

Single-cell RNA sequencing

Start with scRNA-seq basics, then cell-level quality control, then cell-type annotation. QC comes before annotation.

Integration and advanced LISI/silhouette metrics are optional and are not substitutes for basic QC. Follow a suitable question to downstream analysis, cell-cell communication, or trajectory inference for a plausible continuous process. Spatial and CITE-seq are separate options.

Pseudobulk differential expression requires replicated single-cell samples and an appropriate design; it is not a bulk RNA-seq tutorial.

DNA sequencing and variants

For whole-exome sequencing (WES), consult quality-control fundamentals and the data-formats reference as needed, then read reference genomes and annotation before the WES variant-calling template. WES is assay-specific and is not the default route into single-cell analysis.

Microbial sequence analysis

Explore 16S profiling and Prokka genome annotation; check that lesson for the relevant inputs and scope before beginning.

Evolution and phylogeny

Review reference genomes and annotation as appropriate before using the evolutionary phylogeny template.

Tools and references

Install project software only when a lesson needs it. You do not need a cluster to begin.

Software setup and practical references

Micromamba environments isolate a project's software. You need terminal comfort and permission to install packages. The collection is not standardized on one Python or R version; follow each lesson's dependencies.

Continue to command-line Part 2 or Part 3 when needed. In Part 1, zero-byte placeholder files are not sequencing data.

Look up data formats, statistics for independent two-group comparisons, or study design and batch effects as needed. Workflow automation and containers are optional.

HPC and cluster computing (optional)

HPC requires authorized institutional access. Follow local security and scheduler policies. If your project needs a cluster, see connecting to HPC, Slurm basics, job scripts, and HPC support.

Suggested routes, not a required course or a complete analysis pipeline. Lessons include guides, labs, templates, and references.
