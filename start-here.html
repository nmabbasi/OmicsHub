ROADMAP & REQUIREMENTS

Prerequisites, Setup & Learning Outcomes

Start small, then check each lesson for its own software, data, and computing needs.

01COMPUTING

Hardware Requirements

A modern laptop is enough for many foundation exercises.

Check resource needs

Check the chosen lesson's operating-system and memory requirements; needs vary with the tools and input size.

Larger analyses may need HPC or other high-memory computing. Estimate memory, storage, threads, and runtime for the actual data and tools; follow your institution's scheduler policies.

02TOOLS

Software Stack

Install only what your chosen lesson asks for.

See common tools

Follow the lesson's versions and dependencies. The collection is not standardized on one Python or R version. Record your environment and check compatibility.

  • Package managersMamba, Micromamba
  • LanguagesPython (Scanpy, Biopython); R (Seurat, DESeq2)
  • Optional workflowsSnakemake, Nextflow, Docker, Singularity
03PRACTICE

Expected Outcomes

Build the habit of planning, adapting, and checking reproducible analysis.

Try a first milestone

Complete the Command-Line Part 1 lab. Make a disposable project tree, safely copy and move files, and inspect the named zero-byte placeholders; confirm they are not sequencing data.

Check the displayed paths and file sizes. The lesson explains what each output verifies and what it cannot establish; practice templates are not research findings.

A QUICK SELF-CHECK

Pause and check your progress

Strong analysis is more than syntax: understand your data and know how to troubleshoot.

01: SETUP

Can you recreate your environment, record versions, run a small check, and note platform differences?

02: RESOURCES

Can a small test and its logs help you estimate memory and runtime, then request resources within local policy?

03: INTERPRETATION

Can you explain your QC choices and identify which biological or statistical checks come next?
